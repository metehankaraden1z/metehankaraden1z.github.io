A2Crescendo

Python server and Flutter app, in progress

A music rating app where every song gets its own score. Search any album, rate it track by track in half-stars, and Crescendo builds a "Taste DNA" profile from your ratings and shows how closely your taste matches other listeners.

The web version is a single Python server on the standard library with SQLite and MusicBrainz data. The Android app is written in Flutter against the same JSON API.
